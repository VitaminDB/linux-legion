## linux-legion 0.2.0

### Own power profiles
- **Clone** any firmware mode or profile, give it a name, edit or delete it.
- A profile sits on top of a firmware mode (Quiet … Extreme, Custom): own CPU PL1/PL2,
  a **CPU temperature limit**, and — for Custom-based profiles — the firmware limits and fan targets.
- The profile is active while its mode is on (Fn+Q included); picking a built-in mode drops it.
  The header shows the active profile.

### CPU temperature limit in any mode
- Implemented with the Intel TCC offset (`intel_tcc_cooling`), so it works in Extreme too —
  e.g. *Extreme* with the GPU at its full 175 W and the CPU held at 95 °C (verified on a
  Legion Pro 7 16IAX10H under full CPU + GPU load). The BIOS resets the offset on every mode
  switch; the service keeps it.

### CPU and GPU cards
- Firmware power limits are split into side-by-side CPU and GPU cards.
- The GPU card shows the current power limit and draw, and explains why the TGP cannot be raised
  in Custom: the firmware reports a 0–0 range (cTGP 95 W + 15 W Dynamic Boost = 110 W on the
  Pro 7 Gen 10), so full power lives in Performance / Extreme.

### Tray
- "Minimize to tray on close" switch in the left panel; `linux-legion --hidden` starts in the tray;
  a second launch brings the window back.

### Packaging
- Built with syngui-cli from `syngui-release.toml` (`syngui package -w -f arch --install`).
- AUR: `linux-legion` (from the release source), plus new `linux-legion-bin` (prebuilt) and
  `linux-legion-git`.
- New dependencies for the tray: `gtk3`, `libayatana-appindicator`, `xdotool` (libxdo).
- The udev rule also makes the CPU TCC offset writable for the `wheel` group.
